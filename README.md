# 3rr Game — 3rrgame.co

Next.js informational site for **3rr Game** (Android APK guides for Pakistan): download, deposit, withdraw, PC emulator, and SERP-driven blog posts.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Canonical domain

Production canonicals, sitemap, and Open Graph URLs use `https://3rrgame.co`.
